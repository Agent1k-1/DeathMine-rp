# Death☠Mine — ресурс-пак для TAB и скорборда

Оранжево-золотая пиксельная надпись **Death☠Mine**, без RP/РП.
Два размера одной надписи, прозрачный фон, эмблема с оранжевым черепом в списке ресурс-паков.
Обычные буквы, предметы, блоки и главное меню не изменяются.

## Скачать и установить

Готовый архив: [dist/DeathMine-RP.zip](dist/DeathMine-RP.zip).
Его не нужно распаковывать перед установкой в Minecraft.
Для серверной загрузки используйте прямую ссылку и SHA-1 из
[examples/server.properties](examples/server.properties).

1. Остановите сервер и добавьте параметры из примера в свой `server.properties`,
   заменяя существующие одноимённые строки. Не заменяйте весь файл.
2. Для автоматического показа установите совместимую с вашим сервером версию
   [TAB](https://github.com/NEZNAMY/TAB). Сам пак плагинов не содержит.
3. Сохраните резервную копию `plugins/TAB/config.yml`.
   Перенесите **только** разделы `header-footer` и `scoreboard` из
   [TAB-modern.yml](examples/TAB-modern.yml) в существующий конфиг.
   Не добавляйте второй раздел с тем же именем. Если в вашем TAB нет `designs`,
   используйте [TAB-legacy.yml](examples/TAB-legacy.yml).
4. Сохраните YAML как UTF-8. Запустите сервер, выполните `/tab reload`
   от администратора, переподключитесь и примите ресурс-пак.
5. В TAB будет крупный логотип; справа — компактный логотип и статистика.
   Если скорборд не нужен, установите `scoreboard.enabled: false`.

`server.properties` загружает ресурс-пак, но сам по себе не создаёт TAB или скорборд.
В обычном vanilla-сервере используйте команды/датапак для нужных текстовых компонентов.
Для игроков без пака специальные символы будут выглядеть как пустые квадраты.
`require-resource-pack=true` не позволит подключиться при отказе от пака.

## Символы для любого другого плагина

| Назначение | Копировать символ | Unicode | Размер | Пример строки TAB |
| --- | --- | --- | --- | --- |
| TAB | `` | U+E001 | 114 × 16 | `'&f'` |
| Скорборд | `` | U+E002 | 57 × 8 | `'&f'` |

Не копируйте надпись `U+E001` вместо самого символа. В YAML с одинарными кавычками
`\uE001` не преобразуется в символ. Используйте готовые строки из примеров.
Белый цвет `&f` сохраняет цвета текстуры. Не добавляйте жирность `&l` или курсив `&o`.
В других плагинах используйте их собственный синтаксис белого цвета и сброса стилей.
Крупная надпись выше обычной строки: оставляйте пустую строку над ней и под ней.

Дополнительно зарегистрирован отдельный шрифт `deathmine:logo`:

```mcfunction
/tellraw @s {"text":"\ue001","font":"deathmine:logo","color":"white","bold":false,"italic":false}
```

Эта команда подходит для ручной проверки на Java 1.19+ после загрузки пака.
Для компактного варианта замените `\ue001` на `\ue002`.

## Версии

Пак предназначен для **Minecraft Java Edition 1.19–26.3**, последнего стабильного
выпуска по проверенной таблице версий. Bedrock требует отдельного формата пака.
Метаданные: `pack_format: 9`, диапазон форматов 9–97.1.
На старых клиентах до 1.20.2, не понимающих диапазоны форматов, при ручной
установке возможна пометка «для другой версии»; используются обычные bitmap-шрифты.
Совместимость будущих выпусков и снапшотов не заявляется.

Это ресурс-пак, а не средство подключения разных версий игры к серверу.
Для подключения разных клиентов нужны подходящие версии сервера и, при необходимости,
ViaVersion/ViaBackwards. Версия TAB тоже должна поддерживать конкретный сервер.

Метаданные сверены с [mcmeta](https://github.com/misode/mcmeta/tree/summary).
Примеры современного TAB подготовлены по документации
[Header & Footer](https://github.com/NEZNAMY/TAB/wiki/Feature-guide:-Header-&-Footer) и
[Scoreboard](https://github.com/NEZNAMY/TAB/wiki/Feature-guide:-Scoreboard).

## Проверки и обновление

Требуется только Python 3, сторонние зависимости не нужны:

```sh
python3 scripts/build.py
python3 scripts/verify.py
```

Проверены: воспроизводимость сборки, целостность ZIP/PNG, наличие ресурсов,
соответствие исходникам, метаданные, оба символа, YAML примеры и SHA-1/SHA-256.
Игровой клиент и настоящий сервер с TAB в этой среде не запускались;
отображение и интеграцию нужно проверить в игре на используемых версиях.

При обновлении ZIP пересчитайте `resource-pack-sha1` и поменяйте ссылку в
`server.properties` на новый коммит/файл. Ссылки из примера закреплены на коммит,
чтобы архив по ним не менялся без обновления хеша.

Если уже используется ItemsAdder/Oraxen/Nexo или другой серверный пак, объедините
ресурсы и font providers, проверив конфликты U+E001/U+E002. Не заменяйте существующий
пак, если нужны его текстуры. Этот архив содержит только оформление DeathMine.
